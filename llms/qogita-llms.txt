# Qogita

> Qogita is Europe's B2B wholesale marketplace for health and beauty, connecting retailers to a combined catalog of 500+ suppliers and distributors offering 10,000+ brands with guaranteed authenticity for EU and UK retail. Qogita exposes a REST API (api.qogita.com) documented at developers.qogita.com, plus a hosted, OAuth-protected MCP server.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public surface and the artifacts captured in this repository.

## API
- [Qogita API documentation](https://developers.qogita.com/): Developer portal (hosted on Notion) for the api.qogita.com REST API.
- API host: https://api.qogita.com

## Agent access (MCP)
- [Qogita Staff MCP - Production](https://api.qogita.com/staff/mcp): Hosted Model Context Protocol server, OAuth 2.1 (PKCE) protected, scope `staff:mcp`.
- [OAuth Authorization Server Metadata](https://api.qogita.com/.well-known/oauth-authorization-server) (RFC 8414)
- [OAuth Protected Resource Metadata](https://api.qogita.com/.well-known/oauth-protected-resource/staff/mcp) (RFC 9728)
- [OpenID Connect discovery](https://api.qogita.com/.well-known/openid-configuration)
